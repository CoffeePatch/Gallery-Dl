# Media Downloader & Analysis Workspace

Welcome to the root workspace. This repository contains a collection of robust, rate-limit resistant automation tools for downloading media and analyzing accounts across X (Twitter) and Instagram.

To keep the repository clean and modular, the functionality has been split into three independent, purpose-driven directories. 

## Repository Structure

### 1. `account-status-checker/`
A highly optimized Node.js / Playwright script used to scan thousands of X accounts to determine if they are **Active**, **Suspended**, or **Deleted**.
- **Under the hood:** It launches a headless Chromium browser, injects your session cookies, and features strict rate-limit defenses (micro-delays, 150-account macro batches) to prevent API bans. It auto-resumes progress seamlessly from `results.csv`.
- 📖 [Read the detailed documentation](./account-status-checker/README.md)

### 2. `scripts/`
A powerful PowerShell wrapper around `gallery-dl` built exclusively to rip images and videos from X (Twitter) accounts.
- **Under the hood:** It reads your target lists, spawns `gallery-dl` with a highly specific configuration, and maintains a local SQLite archive database so that running the script multiple times *never* downloads the same file twice.
- 📖 [Read the detailed documentation](./scripts/README.md)

### 3. `media-downloader-ig/`
A dedicated PowerShell wrapper around `gallery-dl` for scraping Instagram profiles.
- **Under the hood:** Because Instagram aggressively blocks scrapers, this module is strictly configured to ingest a dedicated `instagram_cookies.txt` file to authenticate its requests and safely archive media.
- 📖 [Read the detailed documentation](./media-downloader-ig/README.md)

---

## Global Input & Output Files
By design, all sensitive authentication files, target lists, and downloaded media remain in the **root** folder. The `.gitignore` is strictly configured so that none of your local data is ever pushed to a remote repository.

**Expected Root Files:**
- `users.txt` / `instagram_users.txt` - Your raw lists of targets.
- `cookies.txt` / `auth.json` / `instagram_cookies.txt` - Your browser session credentials.
- `results.csv` - The output file generated by the Account Status Checker.
- `/Tweets/` and `/Instagram/` - The directories where all downloaded media will be saved.

## Quick Start
To get started with any of the tools, navigate to their respective folders or run them directly from this root context.

Example: running the X (Twitter) archiver:
```powershell
.\scripts\archive.ps1
```

Example: running the Playwright account checker:
```powershell
node .\account-status-checker\x_checker.js --mode check
```
