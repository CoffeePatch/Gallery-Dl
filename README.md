# Media Downloader & Analysis Workspace

Welcome to the root workspace. This repository contains a collection of robust, rate-limit resistant automation tools for downloading media and analyzing accounts across X (Twitter) and Instagram.

## Repository Structure

All tools and scripts are located in the `Scripts/` directory, while settings, targets, and credentials live in the `Config/` directory.

### 1. `Scripts/`
- **`gallerydl_batch_scraper.ps1`**: A PowerShell wrapper around `gallery-dl` built to rip images and videos from X (Twitter) accounts. It processes target lists, uses SQLite for duplicate protection, and automatically skips known tweets.
- **`instagram_auto.ps1`**: A PowerShell wrapper around `gallery-dl` designed for Instagram profile scraping, utilizing session cookies to bypass Instagram's aggressive defenses.
- **`maintenance_manager.js`**: A consolidated utility for maintaining data and scanning accounts. It offers:
  - **Account Status Checker**: Uses Playwright to scan X accounts headless and determine status (Active, Suspended, or Does Not Exist) under `npm run x-check`.
  - **Stats Generator**: Aggregates records and media statistics (`npm run stats`).
  - **Large Video Filter**: Filters large video records out of raw data (`npm run filter-large`).
  - **Thread Separator**: Moves threaded conversations to a separate raw directory (`npm run separate-threads`).
  - **Self-Retweets Cleaner**: Cleans self-retweets from timelines (`npm run clean-retweets`).
- **`thread_manager.js`**: Orchestrates downloading/scraping X threads (via API or browser fallback) and ThreadReaderApp pages, saving them as self-contained HTML readers while tracking archive state in SQLite.
- **`download_media.js`**: A custom concurrent media downloader that fetches photos and videos asynchronously with retries and mapping support.
- **`generate_timeline.js`**: Reconstructs raw JSON data files into self-contained offline HTML timelines.

### 2. `Config/`
This folder holds all sensitive configuration files, target lists, and session state:
- `Config/Cookies/cookies.txt` - Your raw Netscape browser session credentials.
- `Config/Settings/auth.json` - Exported Playwright storage state for the Account Status Checker.
- `Config/Settings/config.json` - `gallery-dl` specific configuration for X.
- `Config/Settings/instagram_config.json` - `gallery-dl` specific configuration for Instagram.
- `Config/Users/threads.txt` / `urls_threadreader.txt` / `urls_twitterthread.txt` - Target queues for the thread archiver.
- `Config/Users/instagram_users.txt` - Targets list for the Instagram scraper.
- `Config/Users/users.txt` - Target usernames list for X/Twitter scrapers and status checker.

### 3. `TweetData/`
All scraped JSON metadata, downloaded media, generated offline timelines, and reports are saved here:
- `/TweetData/RawData/` - Timeline JSON dumps from `gallery-dl`.
- `/TweetData/Media/` - Downloaded media files.
- `/TweetData/Threads/` - Serialized HTML thread reader outputs.
- `/TweetData/AccountStatus/results.csv` - The output generated by the Account Status Checker.

## Prerequisites & Dependencies

- **Node.js**: Version 18 or newer (utilizes built-in `node:test` framework).
- **Python**: Version 3.10 or newer.
- **gallery-dl**: Tested and pinned at version `1.32.3` (see [requirements.txt](file:///c:/Users/hello/Pictures/Gallery-Dl/requirements.txt)). Ensure it is installed and available in your system `PATH`.

## Quick Start

### 1. Run the X (Twitter) Scraper
To begin scraping the timeline media for target users listed in `Config/Users/users.txt`:
```powershell
npm run scrape
```

### 2. Run the Playwright Account Status Checker
To scan all target accounts in `Config/Users/users.txt` headless:
```powershell
npm run x-check
```
*Note: If cookies are expired, run `npm run x-auth` first to open a browser window and log in manually.*

### 3. Archive Thread URLs
To process the thread queues defined in `Config/Users/`:
```powershell
npm run threads
```

### 4. Run the Maintenance Menu
To run the interactive maintenance CLI (for stats, video filtering, cleaning retweets, and more):
```powershell
npm run maintenance
```

### 5. Run the Automated Tests
To run the Node.js unit tests, Python integration tests, and deduplication parity checks:
```powershell
npm test
```
